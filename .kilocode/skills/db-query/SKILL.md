# /db-query — read-only запрос к базе 1С

Выполняет объект `Запрос` через COMConnector и возвращает колонки и строки в JSON или CSV. Скрипт не выполняет произвольный BSL-код и не предоставляет API записи, поэтому подходит для независимой проверки данных после разработки.

## Подключение

Разреши базу через `.v8-project.json` по алгоритму `/db-list`: явно указанная база → ветка Git → `default`. Передай скрипту файловый путь либо сервер и имя базы, а также пользователя и пароль из записи базы. Не печатай пароль в команде, отчёте или ответе пользователю.

COMConnector доступен только на Windows с установленной платформой 1С. По умолчанию скрипт пробует `V85.COMConnector`, затем `V83.COMConnector`.

## Команда

```powershell
python ".kilocode/skills/db-query/scripts/db-query.py" -InfoBasePath "C:\Bases\MyDB" -UserName "Admin" -QueryFile "query.sql" -ParametersJson "params.json" -OutputFile "result.json"
```

## Параметры

| Параметр | Описание |
|----------|----------|
| `-InfoBasePath` | Каталог файловой базы |
| `-InfoBaseServer`, `-InfoBaseRef` | Сервер и имя серверной базы |
| `-UserName`, `-Password` | Аутентификация 1С |
| `-QueryFile` | UTF-8 файл с текстом запроса; предпочтительный способ |
| `-QueryText` | Текст запроса прямо в параметре, только для коротких запросов |
| `-ParametersJson` | UTF-8 JSON-объект скалярных параметров запроса |
| `-OutputFile` | Файл результата; без него результат выводится в stdout |
| `-OutputFormat` | `Json` (по умолчанию) или `Csv` |
| `-MaxRows` | Максимум возвращаемых строк, по умолчанию 10000 |
| `-ComProgId` | Явный ProgID COMConnector, если автоопределение не подходит |

Должен быть задан ровно один источник запроса: `-QueryFile` или `-QueryText`. Для JSON результат имеет поля `ok`, `columns`, `rowCount`, `truncated`, `rows`.

### Параметры запроса

```json
{
  "ИмяНоменклатуры": "Бутылка",
  "МинимальныйОстаток": 0
}
```

Передавай строки, числа, boolean или `null`. Для независимой проверки ссылочного значения фильтруй запрос по коду, наименованию или другому скалярному полю; навык намеренно не создаёт и не ищет ссылки через прикладные менеджеры.

## Проверка результата

Сохраняй результат в журнал или JSON-файл, когда он служит доказательством приёмки. Сопоставляй значения по устойчивым ключам, а не по порядку строк. Если `truncated=true`, сузь запрос или осознанно увеличь `-MaxRows`.

Перед утверждением «данных нет» выполни отдельный контрольный запрос без отборов интерфейса и проверь `rowCount`. Пустая таблица формы не доказывает пустую базу: на неё влияют поиск, сегмент, текущая страница и пользовательские настройки. Для сценария, зависящего от остатков, сначала найди read-only запросом объект с ненулевым остатком, затем используй его в клиентской проверке.
